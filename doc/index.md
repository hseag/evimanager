# eviManager at a Glance

`eviManager` is the Windows service application for HSE AG's Colibri instruments. It detects a connected `eviDense UV` Photometer or `eviFluor Duo` Fluorometer over USB, shows device information, updates firmware, runs self-tests, and exports technical reports as PDF files.

## What is eviManager for?

eviManager is used by service technicians to maintain supported Colibri instruments:

- detect the connected instrument and read its serial number and firmware version
- update the instrument firmware from a `.srec` file
- run an instrument self-test and export the result as a PDF report
- set the instrument's status LED during service checks
